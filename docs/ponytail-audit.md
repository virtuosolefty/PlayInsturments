# Repository simplification audit

Audited on October 4, 2026, at commit `b8190ea`, using ponytail-audit. Scope: unnecessary code, duplicated logic, and avoidable abstraction. This report proposes changes; it applies none.

The repository inventory contains 454 tracked files. The review scanned source, unit and browser tests, scripts, styles, configuration, workflows, and documentation for references and duplication, and checked the dependency declarations against their uses. Binary assets were inventoried rather than treated as source code. Deletion candidates were checked across tracked text, including tests, fixtures, documentation, and string references. Standalone executable scripts were also inspected for useful behavior; absence of an import alone is insufficient to call a script dead.

Ranked by estimated net lines removed, biggest cut first. Estimates include comments and blank lines and allow for replacement code; they are planning estimates, not a measured patch.

1. **delete:** Cut the 163-line obsolete MIDI generator: nothing calls it, its `jsmidgen` import is absent from the declared dependencies, and its final loop creates a buffer but only logs filenames instead of writing files. Replacement: nothing; retain the working `@tonejs/midi` generator in `scripts/generate-anirudh-songs.mjs`. Estimated saving: 163 lines. [scripts/create-anirudh-midis.mjs:1](../scripts/create-anirudh-midis.mjs#L1).

Estimated net saving: 157 lines after replacement. [src/lib/StorageService.js:35](../src/lib/StorageService.js#L35), [src/hooks/useAppData.js:15](../src/hooks/useAppData.js#L15).
